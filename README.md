# 🐉 Dragon-Creator

**Инструмент для создания своих добрых драконов с седлом.**

Создавай персонажей, выбирай вид, цвет чешуи и глаз, седло и характер — затем садись верхом и лети над тихими долинами.

## ✨ Возможности

- 🎨 Кастомизация внешности: чешуя, глаза, седло
- 🐉 Выбор вида: тёплый, лесной, речной, звёздный
- 📝 Описание характера дракона
- 🚀 Полёт над картой неба с ориентирами
- 💾 Экспорт/импорт JSON своих драконов
- 🌟 Примеры готовых драконов из логова (в том числе **Лунная роса** — мягкое седло для полётов над росистыми лугами под лунным светом)

## 🚀 Как запустить

Просто открой `index.html` в браузере. Или запусти локальный сервер:

```bash
# Например, с Python
python -m http.server 8000
```

Затем открой [http://localhost:8000](http://localhost:8000).

## 🐉 Примеры драконов

В `sample-dragons.json` есть готовые примеры:

- **Зорь** — тёплый дракон с кожаным седлом
- **Звёздный дождь** — полёты под падающими звёздами
- **Золотой закат** — тёплые полёты над закатом
- **Лунная роса** — мягкое седло для росистых лугов под луной

Нажми «Примеры из логова» в интерфейсе, чтобы загрузить их.

## 💎 Структура

- `index.html` — интерфейс кузницы драконов
- `styles.css` — тёплые стили
- `app.js` — логика создания и полётов
- `sample-dragons.json` — готовые примеры
