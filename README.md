# Dragon-Creator

Логово для создания **добрых драконов с седлом**.

Кастомизация вида, цвета, характера и седла — в браузере, без сборки.

## Как запустить

Открой `index.html` в браузере. Стая хранится в `localStorage`.

Чтобы подтянуть примеры из `sample-dragons.json`, удобнее открыть папку через простой локальный сервер.

## Что умеет сейчас

- выбрать вид, чешую, глаза и седло
- задать имя и характер
- сохранить стаю в логове (локально)
- экспортировать и импортировать JSON дракона или целой стаи
- взять примеры Зорь, Ивы, Грома, Луны (облачное седло для тихих ночных полётов), Весны (мягкое седло для весенних ветров) и Осени (мягкое седло для золотых осенних листьев)
- взлететь: карта неба с ориентирами и мягкой посадкой
- сесть верхом на дракона из стаи
