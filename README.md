# Dragon-Creator

Логово для создания **добрых драконов с седлом**.

Кастомизация вида, цвета, характера и седла — в браузере, без сборки.

## Как запустить

Открой `index.html` в браузере. Стая хранится в `localStorage`.

Чтобы подтянуть примеры из `sample-dragons.json`, удобнее открыть папку через простой локальный сервер.

## Что умеет сейчас

- выбрать вид, чешую, глаза и седло
- задать имя и характер
- сохранить стаю в логове (локально)
- экспортировать и импортировать JSON дракона или целой стаи
- взять примеры Зорь, Ивы, Грома, Луны (облачное седло для тихих ночных полётов), Весны (мягкое седло для весенних ветров), Осени (мягкое седло для золотых осенних листьев), Зимы (мягкое седло для снежных долин и тёплого уюта), Лета (мягкое седло для солнечных лугов и тёплых озёр), Рассвета (мягкое седло для утренних полётов над росистыми холмами), Сумерок (мягкое седло для вечерних полётов над тихими долинами), Полночи (мягкое седло для полночных полётов над звёздными долинами), Полдня (мягкое седло для полуденных полётов над золотыми полями), Заката (мягкое седло для закатных полётов над оранжевыми холмами), Тумана (облачное седло для тихих полётов сквозь туман) и Инея (мягкое седло для морозных полётов над инейными долинами), Росы (мягкое седло для полётов над росистыми лугами), Светлячка (мягкое седло для полётов над светящимися полянами в сумерках), Авроры (мягкое седло для полётов над северным сиянием), Радуги (мягкое седло для полётов над радугами после дождя), Зарницы (мягкое седло для полётов над зарницами над летним лугом)
- взлететь: карта неба с ориентирами и мягкой посадкой
- сесть верхом на дракона из стаи
